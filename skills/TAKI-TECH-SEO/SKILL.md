# Skill: TAKI-TECH-SEO

Purpose: investigate technical SEO issues safely.

## Scope
- robots directives
- XML sitemap
- status codes
- redirects
- canonical
- meta robots
- schema
- URL consistency
- internal technical links
- indexability signals
- HTTPS

## Method
1. Observe public behavior.
2. Reproduce.
3. Identify whether the problem is page-level, template-level, plugin/config-level or infrastructure-level.
4. Produce evidence.
5. Propose the smallest reversible fix.
6. Use staging before any production change.

## Important
Do not equate `not indexed` with a technical error without evidence.
Do not change Rank Math or WordPress production settings without approval.

## Project rules
Read references/AGENTS.md before execution. Independently verify every hypothesis. Codex supports roles 00–06 and cannot authorize production changes.
